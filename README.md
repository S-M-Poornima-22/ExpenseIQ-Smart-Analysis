💰ExpenseIQ — Smart Expense Tracking & Analytics

> **Track it. Analyze it. Understand it.**

Personal Expense Tracker is a simple web application built to help users record and manage their everyday expenses in an organized way.

The project also connects expense data with **Power BI**, turning daily transactions into clear visual insights that makes easier to understand.

---

## 💡 The Idea Behind the Project

Managing small daily expenses can become difficult when there is no clear record of where the money is going.

This project was built to provide a simple place to **record, manage, and analyze expenses** while exploring how everyday data can be transformed into meaningful insights.

> **From recording every expense to seeing the bigger picture.**

---

## ✨ What You Can Do

* Add and record daily expenses
* Edit existing expense details
* Search through expense records
* Filter expenses based on different details
* Organize spending using categories
* Track payment methods and spending amounts
* Store records using SQLite
* Analyze expense data using Power BI

---

## 📊 From Data to Insights

The project combines expense management with data analytics.

The basic workflow is:

**Add Expense → Store Data → Manage Records → Prepare Data → Power BI → Insights**

Power BI helps transform the recorded expenses into visual information such as spending trends, category-wise expenses, and payment method patterns.

## ⚙️ How It Works

**1. Add an Expense**
Enter the date, category, description, amount, and payment method.

**2. Store the Record**
The expense is saved in the SQLite database.

**3. Manage Your Expenses**
Search, filter, edit, and review existing records.

**4. Analyze the Data**
Expense data is prepared for visualization.

**5. Explore Insights**
Power BI turns the collected data into an interactive dashboard.
